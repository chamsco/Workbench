## Audit of Workbench/Backspace (v0, at 2ed620d)

Wrote `docs/AUDIT-2026-10-12.md` and `docs/PLAN-NEW-FEATURES.md`.

- Core loop is healthy: `cargo test -p backspace-core` → 56 unit + 5 e2e green.
  The one failing test (`runner/tests/http.rs::bad_agent_addresses_say_so`) is
  environmental: `HTTP_PROXY` is set in this sandbox and only the board bridge
  builds its reqwest client with `.no_proxy()`. That is a real bug too —
  localhost (Ollama, local routers, A2A, followed machines) is proxy-routed.
- Top gaps found: no multi-account/failover (one credential per CLI, 429 retried
  3x then hard-fail); restart marks workers Failed (no true resume); companion
  binds 0.0.0.0 with a webhook path that bypasses the token; unbounded state
  growth + full-state IPC fan-out; panic surface (`lock().unwrap()`, `agents[id]`).
- `docs/AUDIT.md` (7 Oct) is stale: "opening a project commits your work" was
  fixed by `git::ensure_run` (throwaway index + `commit-tree`, secret filtering),
  and the planner-on-subscription gap is closed.
