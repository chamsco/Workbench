CLASSIFICATION
  spec_gate : timing. `Chats::is_busy` goes false when spawn_reply removes its `running` entry (chat.rs, `me.running.lock().unwrap().remove(&tid)`),
              which runs BEFORE `me.finish(..)` and `me.file_spec(..)` attach the verdict. The test treated "not busy" as "verdict present".
              A product ordering that the UI absorbs (it is poked again after the verdict); the test's wait condition was wrong.
              Fix is test-only: wait for the verdict itself, inside the same 30 s limit. chat.rs is untouched.
  webhook   : shared state. The two tests in webhook.rs each call std::env::set_var("BACKSPACE_DATA", <own dir>) on the one process-wide environment, and
              the fleet reads it again as it works. Run together one test's agent store is the other's folder: the bot's secret is unknown to the
              server that answers (401). 0/60 alone, 8/80 together. Fix is test-only: a static mutex serialises the two tests.
              No webhook product code was changed.
