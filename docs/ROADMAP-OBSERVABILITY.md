# Roadmap: Stats (harness observability) in Backspace

Source analysis: [HARNESS-REVIEW-2026-10-25.md](HARNESS-REVIEW-2026-10-25.md), generated by
`harness_summary.py` + `render_dashboard.py` (stdlib Python, read-only, in `Documents/code/harness-observability`).

## Where it fits

| Place | Verdict | Why |
|---|---|---|
| **Home page, "Stats" tab** | Yes, primary | Summary strip (calls, prompts, error rate, tokens, p95), tokens by model, trace list. It is what you look at weekly. |
| **Settings -> Tracing** | Yes, config only | Already holds the OTLP export. Add: sources on/off, window (7/30 d), "exclude this session", privacy mode. |
| **Existing `Trace.tsx` waterfall** | Reuse | Same waterfall component renders imported sessions, so Backspace chats and CLI sessions look alike. |

## How (Rust, not Python)

1. `crates/core/src/usage.rs` (new): readers for each source -> one `SessionStats` shape. Reuse `harnesses::known()` for the device's installed agents and `trace.rs` `Trace/Span` for detail.
   - Claude Code `~/.claude/projects/**/*.jsonl` (dedupe by `message.id` and `tool_use.id`; subagent files keyed by path).
   - Codex `~/.codex/sessions/**/*.jsonl` (sum `token_usage_record.usage`, never `thread_token_usage`).
   - Backspace's own `<data>/traces/`.
   - Later: Gemini CLI, OpenCode, Cursor, any harness with a local log. Each is one small parser behind a `trait SessionSource`.
2. Tauri command `usage_summary(days)` returns the JSON the Python script writes today (`harness-summary.json` is the contract).
3. Web: `app/Stats.tsx` (home tab) + a Settings block. No new charting dependency; port the SVG bars from `dashboard.html`.
4. "Propose changes" button: runs the HARNESS.md logic and shows a diff for CLAUDE.md / AGENTS.md. Never writes without a click.

## Rules carried over (non-negotiable)

- Read-only on other tools' logs. Counts and timings only; snippets <= 10 words with paths, URLs, keys and long ids stripped. Never store tool inputs or outputs.
- Anything a log doesn't record shows "not logged". No invented numbers.
- Scores (health, task type) are labeled "heuristic".
- Remote/phone devices: report per device, computed on that device; only the summary JSON crosses the link, never raw logs.
