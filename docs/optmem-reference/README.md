# OptMem Reference

Source files from [github.com/VictorTaelin/OptMem](https://github.com/VictorTaelin/OptMem),
fetched 21 Oct 2026 for the exploration in `../OPTMEM-EXPLORATION-2026-10-21.md`.

These are kept verbatim for reference. They are not part of Workbench's
build; they are the upstream source the exploration analyses.

- `memo` — the tool: one Python file, no dependencies (~500 lines)
- `test.py` — the test suite: 2,000 synthetic memories, ~600 lines
- `install.sh` — the installer: downloads `memo`, runs `init`
