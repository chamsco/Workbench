01  Project rail — full height One switcher for the whole app

The project rail runs the full height and is the only project switcher. The account sits at the bottom with settings and update beside it. Switching a project rewrites the session groups.

02  Sidebar — modes & actions Code, Work, Design, Swarm on top

Modes sit at the top of the sidebar, above the action strip. The old top-bar switcher spot now holds the collapse-sidebar button. Limits reveals on hover and pins on click.

03  Sessions — where they run This Mac, cloud, or a machine

Sessions are grouped by execution location: local, cloud, and a connected machine, each with a count. Connect machine adds a cloud or SSH target.

04  Composer — agent filters Filters live under the chatbox

All agents, Claude Code, Codex and Cursor sit below the composer instead of in the top bar. The top bar is left with the title, panel controls and the primary action.

05  Swarm — team setup Teams are configured, then run

A lead, two workers and an add-agent tile, connected as a swarm. Team settings cover runs-on, parallelism, autonomy, shared context and budget.
