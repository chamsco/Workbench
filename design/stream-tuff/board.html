Stream tool blocks: shell block, live step, model label

The rest of Tuff UI's coding-agent look, on top of the ledger (board A, 21 Nov): one grey line per finished step. Asked for: a shell block ($ command, status pill, "N lines" and Copy), a live step card (pulsing dot, timer, Stop), the model name above each reply, Copy on opened step output. tuffui.com was not reachable from the build machine, so the shapes follow the design system's Tuff tokens (inset radius 12, tag 6) rather than a fresh read of the page.

Pick A. Charles chose the ledger (one grey line per finished step) on 21 Nov; B undoes it for commands, and a 20-command reply becomes 20 boxes. B's docked card also duplicates the composer's Stop and moves the live step away from where it sits in the transcript. A keeps the ledger and gives each thing its block only when it matters: when you open it, or while it runs.

Details of A as built

  • Shell block: header $ command (full command, not the 56-char label) with a pill: Running (neutral), Done (neutral check), Failed (bad). Body is the output in mono, 220px max then it scrolls. Footer "N lines" and Copy (copies the output).
  • Other opened output (a Thought): the same inset with a Copy at the top right.
  • Live card: only the last running step of a reply that is still being written. Pulsing dot (still under reduced motion), the shimmer label, a m:ss timer, Stop (stops the stream, the same as the composer's Stop).
  • Model label: above each reply, 11.5px fg3. It leaves the meta line under the reply, which keeps author and cost.
  • Colour: per the design system, status is a glyph and a word; only failure adds colour. The pulsing dot is fg2, not the accent (the accent means "this wants you").
