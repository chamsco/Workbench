This reverses my earlier rule that the sidebar list stays when you switch. That rule made the sidebar the same everywhere, and you called it stuck. I'm following the new one.

1. One sidebar frame, six lists

Top row, the six buttons and the footer never change. Only the zone between them does.

AgentsNew chat, New group, then Agents with their figures and moods, then Crew (group chats). The page keeps only the chat and the 200px agent drawer, so the roster is not shown twice.
Folders"All folders" opens the glass overview. Each folder opens its detail. Librarian proposals sit at the bottom as an outlined folder.
Automations, Usage, LibraryThe page's own tabs and lists move left: Library's Proposals, Notes, Graph and Librarian become the first four rows, Usage lists the tools, Automations lists yours and recent runs. Usage has no create action, so it has no top button.
Folded railDoes not change per destination. It has no room for lists. Search moves to the top of it, under the window buttons.

4. Global search

The icon sits beside the retract button. Click it, or press Cmd+K on Mac or Ctrl+K on Windows and Linux, from any screen.

On Agents, nothing typed yet. Recent, actions for this destination, then places to go
On Streams, typing "pr". Streams first, then everything else that matches
Context, not filterThe current destination's results come first and the rest follow under "Elsewhere". Filtering by destination would hide matches and look like a broken search.
What it searchesStreams, agents, crews, folders, notes, automations, actions and settings pages. Streams and notes by title and text where core already indexes it; folders and Library entries are marked Example until core has them.
KeysUp and down to move, Enter to open, Esc to close. Cmd+K again closes it. On Windows and Linux, Ctrl+K goes to the terminal pane when one has focus (it deletes to end of line there), so use the icon or Ctrl+Shift+K in that case.
Opening a resultA stream opens in Streams, an agent or crew in Agents, a folder in Folders, a note in Library. The sidebar swaps with the destination.

5. Decision card

PickA, the list swaps, plus the Needs-you pill, plus a ranked global search.
ComprehensionThe sidebar title row and the button highlight say where you are, and the list below always belongs to that place. B shows two unrelated lists at once.
Interaction costReaching a stream from another destination is one click on the Streams button, or Cmd/Ctrl+K and a few letters. Today it is the same, but the lists duplicated.
LoadOne list at a time, no second scroll area. B costs 236px of agents before any stream is visible.
Discoverability"New chat" and "New group" appear exactly where you create things. Search is an icon with a tooltip, not a hidden shortcut.
TimingThe sidebar swap is a 120ms crossfade of the list only, with the frame fixed, so nothing jumps. The palette opens in 100ms with the input focused.
ConsistencyEvery destination follows the same shape: a primary action, then a list, with the same row height and selected style as Streams.
AccessibilityThe palette is a dialog with a labelled input and a listbox. Arrow keys move, results are announced, focus returns to where you were on close. The icon has a tooltip and a label.
What it costsStreams are one click away rather than always listed. The pill softens that, not fully: a stream that needs you shows as a count, not as its title, outside Streams.
LimitsReal data today: streams, agents, notes. Crews, folders, automation runs and the Librarian's proposals are Example until core has them, and are marked as such in lists and results.
