2. New stream, apart from the working directory

The folder is filing. The directory is where the tool runs. They are two fields.

After the first exchange the stream shows the Librarian's proposal above the composer:

Why two fieldsToday core has one: a stream's project is the folder its tool runs in, so filing a stream would change where it runs. A new folder field on the stream fixes that. It is a core change, so it comes with the Folders page.
DefaultNo working directory. The tool asks the first time it needs to edit files and the answer is kept for that stream. The cost is one extra question on the first "fix this in workbench".
FilingThe Librarian proposes a folder from what the stream mentions, or proposes a new one. Nothing moves until you accept. You can name a folder yourself at any time.
Existing streamsThey keep their directory and get a proposed folder from it. Nothing is re-filed without an Accept.
